Backend setup

This extension sends your selected Wikimedia image, bounded Wikipedia context, and optional narration text to http://127.0.0.1:8000. Local description and Kokoro speech run on your computer. If Groq descriptions or Boson voices are selected, the corresponding image/context or narration text is sent to that provider. Keep provider API keys in the backend's private .env file, never in this extension.

Copy the extension ID from Chrome's extension manager into the backend's ALLOWED_EXTENSION_ID setting and restart it.
